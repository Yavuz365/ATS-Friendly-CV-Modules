# ATS-Friendly CV Modules

Master data hub for ATS-friendly CV modules, job & keyword analysis, and automation workflows. Designed for integration with Gemini, ChatGPT, Copilot, and n8n workflows.

## 📋 Overview

This repository provides modular, ATS-optimized CV templates and analysis tools to help job seekers create effective resumes that pass Applicant Tracking Systems (ATS) while impressing hiring managers.

**Key Statistics:**
- 98% of Fortune 500 companies use ATS
- 75% of resumes are rejected before reaching a human
- Proper optimization can increase interview callbacks by 40%+

### 1. Choose Your Template
Select a complete CV example from `templates/examples/` that matches your target role, or build your own using modular sections from `templates/sections/`.

Follow the guidelines in `docs/ats-optimization-guide.md` to ensure your CV passes ATS screening.

## 🎯 ATS Optimization Tips

1. **Use Standard Formatting** - Single column, standard fonts, simple bullets
2. **Include Keywords** - Match job posting language naturally
3. **Quantify Achievements** - Use numbers, percentages, dollar amounts
4. **Standard Section Headers** - Use recognizable section names
5. **Save Correctly** - .docx or clean .pdf format
