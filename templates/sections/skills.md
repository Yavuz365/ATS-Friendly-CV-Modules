# Skills Module

## ATS-Friendly Format

```
SKILLS

Technical Skills: [Skill 1], [Skill 2], [Skill 3], [Skill 4], [Skill 5]
Programming Languages: [Language 1], [Language 2], [Language 3]
Tools & Technologies: [Tool 1], [Tool 2], [Tool 3], [Tool 4]
Soft Skills: [Skill 1], [Skill 2], [Skill 3]
Languages: [Language 1 (Proficiency)], [Language 2 (Proficiency)]
```

## Guidelines

- Group skills by category for readability
- List most relevant/in-demand skills first
- Include keywords from job descriptions
- Be honest about proficiency levels
- Update regularly as you acquire new skills

## Example

```
SKILLS

Programming Languages: Python, JavaScript, TypeScript, Java, SQL, Go
Frameworks & Libraries: React, Node.js, Django, FastAPI, TensorFlow
Cloud & DevOps: AWS (EC2, S3, Lambda, RDS), Docker, Kubernetes, Jenkins, Terraform
Databases: PostgreSQL, MongoDB, Redis, Elasticsearch
Tools: Git, JIRA, Confluence, Figma, Postman
Methodologies: Agile/Scrum, Test-Driven Development, CI/CD
Soft Skills: Team Leadership, Technical Communication, Problem Solving
Languages: English (Native), Spanish (Professional), Mandarin (Conversational)
```

## ATS Tips

- Use exact skill names from job postings
- Include both acronyms and full names (AWS - Amazon Web Services)
- Avoid skill ratings or bars (ATS cannot parse graphics)
- List skills in a simple format, not in tables or columns
- Include both hard and soft skills
- Don't exaggerate proficiency levels
