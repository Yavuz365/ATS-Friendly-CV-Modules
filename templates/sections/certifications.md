# Certifications Module

## ATS-Friendly Format

```
CERTIFICATIONS

[Certification Name] | [Issuing Organization] | [Date Obtained/Expiration]
[Certification Name] | [Issuing Organization] | [Date Obtained/Expiration]
```

## Guidelines

- List most relevant certifications first
- Include certification ID if applicable
- Note expiration dates for time-sensitive certifications
- Group by category if you have many certifications
- Keep certifications current and relevant to target role

## Example

```
CERTIFICATIONS

AWS Certified Solutions Architect - Professional | Amazon Web Services | 2023 (Valid through 2026)
Certified Kubernetes Administrator (CKA) | CNCF | 2022
Professional Scrum Master I (PSM I) | Scrum.org | 2021
Google Cloud Professional Data Engineer | Google Cloud | 2023
Project Management Professional (PMP) | PMI | 2020 (Valid through 2026)
```

## ATS Tips

- Use official certification names exactly as issued
- Include both acronym and full name for recognition
- List credential IDs for verification
- Separate active from expired certifications
- Use standard section headers (Certifications, Professional Certifications, Licenses & Certifications)
