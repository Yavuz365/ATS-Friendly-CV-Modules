# Work Experience Module

## ATS-Friendly Format

```
WORK EXPERIENCE

[Job Title]
[Company Name] | [City, State/Country] | [Start Date] - [End Date/Present]

• [Action verb] + [task/responsibility] + [result/impact with metrics]
• [Action verb] + [task/responsibility] + [result/impact with metrics]
• [Action verb] + [task/responsibility] + [result/impact with metrics]
```

## Guidelines

- List positions in reverse chronological order
- Use consistent date formatting (MM/YYYY or Month YYYY)
- Start each bullet with a strong action verb
- Quantify achievements with numbers, percentages, or dollar amounts
- Focus on accomplishments, not just duties
- Include 3-6 bullet points per role

## Example

```
WORK EXPERIENCE

Senior Software Engineer
Tech Solutions Inc. | San Francisco, CA | January 2020 - Present

• Architected and deployed microservices handling 10M+ daily requests, improving system reliability to 99.9% uptime
• Led migration from monolithic architecture to AWS-based cloud infrastructure, reducing operational costs by 40%
• Mentored team of 5 junior developers, conducting weekly code reviews and technical training sessions
• Implemented CI/CD pipeline using Jenkins and Docker, decreasing deployment time from 4 hours to 30 minutes

Software Engineer
StartupXYZ | New York, NY | June 2017 - December 2019

• Developed RESTful APIs using Python/Django serving 500K+ monthly active users
• Collaborated with product team to deliver 15+ features on schedule, improving user engagement by 25%
• Optimized database queries reducing average response time from 2s to 200ms
```

## Strong Action Verbs

| Achievement | Leadership | Technical | Communication |
|-------------|------------|-----------|---------------|
| Achieved | Coordinated | Architected | Collaborated |
| Delivered | Directed | Automated | Facilitated |
| Improved | Led | Built | Presented |
| Increased | Managed | Deployed | Trained |
| Reduced | Mentored | Developed | Documented |

## ATS Tips

- Use standard section headers (Work Experience, Professional Experience, Employment History)
- Avoid using tables for job entries
- Spell out abbreviations at first use
- Include keywords from job descriptions naturally in bullet points
- Use simple bullet points (•, -, *)
