# Professional Summary Module

## ATS-Friendly Format

```
PROFESSIONAL SUMMARY

[Role/Title] with [X years] of experience in [industry/field]. 
Proven track record in [key achievement 1], [key achievement 2], and [key achievement 3]. 
Skilled in [relevant skill 1], [relevant skill 2], and [relevant skill 3]. 
[Optional: certification or notable accomplishment].
```

## Guidelines

- Keep to 3-5 sentences maximum
- Include target role keywords
- Quantify achievements when possible
- Avoid first-person pronouns (I, me, my)
- Tailor to each job application

## Example

```
PROFESSIONAL SUMMARY

Senior Software Engineer with 8+ years of experience in full-stack development. 
Proven track record in delivering scalable microservices architecture, reducing deployment time by 60%, 
and mentoring teams of 5+ developers. Skilled in Python, JavaScript, AWS, and Agile methodologies. 
AWS Certified Solutions Architect with a passion for clean code and continuous improvement.
```

## ATS Tips

- Use the exact job title from the posting if applicable
- Include industry-specific keywords
- Front-load with the most important information
- Avoid graphics, icons, or special formatting
- Use standard section headers (Professional Summary, Summary, Profile)
