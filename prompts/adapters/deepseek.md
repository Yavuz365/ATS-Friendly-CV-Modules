# DeepSeek Adaptörü

Master Prompt'a ek olarak şu talimatları ekle:

```
## EK TALİMATLAR (DeepSeek)
- Teknik analizi derinleştir (BM25 bileşenlerini açıkla)
- Scoring mantığını adım adım göster
- Keyword ağırlıklarını sayısal olarak listele
- Gap analizinde kapatma stratejisi öner
```

## Güçlü Yanları
- Teknik/analitik düşünme
- Maliyet-etkin (düşük API maliyeti)
- Uzun çıktı kapasitesi

## Dikkat
- Türkçe performansı İngilizce'den düşük olabilir
- Formatı bazen bozabilir — açık format talimatı ver
