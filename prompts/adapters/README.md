# AI Araç Adaptörleri

Her LLM'in farklı güçlü yanları ve format tercihleri vardır. Bu adaptörler Master Prompt'u her araca optimize eder.

| Adaptör | Araç | Güçlü Yanı |
|---------|------|------------|
| `chatgpt.md` | ChatGPT (GPT-4o) | Yapısal çıktı, markdown format |
| `claude.md` | Claude (Sonnet/Opus) | Uzun bağlam, analitik düşünme |
| `gemini.md` | Gemini (Pro/Ultra) | Çok-dilli, hızlı analiz |
| `copilot.md` | Microsoft Copilot | M365 entegrasyonu, Word format |
| `perplexity.md` | Perplexity | Araştırma, güncel veri |
| `deepseek.md` | DeepSeek | Teknik analiz, maliyet-etkin |

## Kullanım

1. `master-prompt-TR.md` veya `master-prompt-EN.md`'yi aç
2. İlgili adaptör dosyasındaki ek talimatları sona ekle
3. JD + Framework CV'yi yapıştır
4. Çıktıyı al → motor ile skorla
