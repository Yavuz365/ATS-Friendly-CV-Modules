# ChatGPT (GPT-4o) Adaptörü

Master Prompt'a ek olarak şu talimatları ekle:

```
## EK TALİMATLAR (ChatGPT)
- Çıktıyı markdown formatında ver
- Her bölümü ayrı code block içinde yaz (kolay kopyalama için)
- Sayısal metrikleri **kalın** yaz
- Gap analizini tablo formatında sun
- Scoring bölümünde bileşenleri liste olarak göster
```

## Güçlü Yanları
- Yapısal markdown çıktısı
- Talimat takibi yüksek
- Keyword entegrasyonu iyi

## Dikkat
- Uzun Framework CV'lerde token limiti kontrol et
- "Daha fazla detay" yerine tek seferde tam çıktı iste
